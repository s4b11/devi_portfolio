# Use OKF for project knowledge

The requested workflow uses OKF v0.2 Markdown and YAML for project knowledge, root agent instructions for discovery and maintenance, and the repository's Git history for tracking changes over time.

This keeps handovers portable across coding agents and lets contributors review knowledge updates with related code. Contributors start with the [current state](/current-state.md), follow the relevant topics, and verify implementation claims against source and tests.
